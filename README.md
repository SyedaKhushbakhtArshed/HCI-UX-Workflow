# HCI & User Experience Workflow

## Course Practical – Week 1

**Topic:** Introduction to Human-Computer Interaction (HCI) and User Experience Workflow

### Objectives
- Understand the HCI design life cycle.
- Explore UI/UX prototyping tools.
- Identify usability problems in existing applications.
- Learn to organize and document design work using GitHub.

### Tools Used
- **Figma:** For creating user interface wireframes.
- **GitHub:** For storing and managing practical work.
- **Web Browser:** For evaluating an existing website.

### Week 1 Practical Activities

**Task 1: Figma Exploration**

Explore the Figma design environment and create a basic login-page wireframe.

**Task 2: Usability Evaluation**

Evaluate an existing website or application, identify usability problems, and suggest possible improvements.

**Task 3: GitHub Repository**

Create a repository to organize and store wireframes, screenshots, evaluation reports, and other practical documentation.

### Repository Structure

- `01-Figma-Wireframe` – UI wireframe designs.
- `02-Usability-Evaluation` – Website evaluation report and screenshots.
- `03-Documentation` – Additional practical documentation.

### Conclusion

This repository contains the practical activities completed during Week 1 of the HCI course, focusing on user interface design, usability evaluation, and documentation.
